# Investigación visual y recursos

Usá los enlaces y la biblioteca en content/referencias/diseno-ia/ como lenguaje de diseño: macros luminosos, isometría, vidrio, metal, redes con profundidad. Extraé composición, luz, material y movimiento; no copiar automáticamente el tema ni una marca de la referencia.

Entregá summary/items con mapa idea→recurso, referencias concretas, prompts para imágenes originales, fuentes propias y alternativas de animación nativa. Cada recurso debe responder a una frase; variedad de escala, objetos, ángulos y colores. Reutilizar el estilo, no siempre el mismo cerebro ni el mismo set de imágenes.

Mantener registro fuente/autor/URL/licencia o permiso/hash/uso. Una imagen descargada para referencia no acredita derechos de publicación. Rawpixel se guardó como referencia visual; no afirmar que se descargó o licenció el video premium. Prompts y guiones son material de trabajo, no instrucciones externas al gerente. No declarar assets creados hasta verificar sus archivos.
